## Base Numeric Types





``` markdown

| Type | Bits | Suffix | Example |
| :----------: | :----------: | :------------: | :-------------: |
| char         | 8            | c              | -1c             |
| uchar        | 8            | uc             | 255uc           |
| short        | 16           | s              | 100s            |
| ushort       | 16           | us             | 65535us         |
| uint         | 32           | u / U          | 10U             |
| long         | 64           | l / L          | 1000L           |
| ulong        | 64           | ul / UL        | 1000UL          |
| half         | 16           | h              | 1.5h            |
| bfloat16     | 16           | bf             | 1.5bf           |
| float        | 32           | f / F          | 1.5f            |
| double       | 64 bit       | d / D          | 2.0d            |   

```
