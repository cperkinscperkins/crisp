# Floating Point Only Operations ⚠️


Crisp provides the following operations for floating point numbers:

#### Unary Operations 📝

The Unary Operations take just a single argument.
Example:
```
(sqrt x)
```

- `sqrt`
- `rsqrt`
- `exp`   ; `(exp x)` calculates $e^x$
- `log`
- `log2`
- `sin`
- `cos`
- `tan`
- `asin`
- `acos`
- `atan`


#### Binary Operations  📝
- `pow`   => `(pow base exponent)`
- `atan2` => `(atan2 y x)`
