

### Short

Crisp eliminates the GPGPU compromise. It is a strictly evaluated, non-Turing complete GPGPU language that guarantees kernel termination and mathematically proven auto-differentiation, while automatically mapping high-level constructs directly to bare-metal hardware constraints. Write beautiful math; get blistering, topology-aware silicon execution.

### Technical

Historically, GPU programming forces a trade-off: high-level abstraction with terrible performance, or hardware-optimized code that is brittle and unreadable. Crisp breaks this cycle. Built on a Lisp frontend, it acts as a fully topology-aware compute engine. By integrating Scalar Replacement of Aggregates (SROA), machine-aware loop unrolling, and block-scoped precision controls natively into the compiler, Crisp handles the memory hierarchy and thread contexts for you. You get the expressiveness of multidimensional tensors with the execution speed of raw scalar registers—all statically analyzed at compile time.

### Design Philosophy

Crisp is designed for an era where correctness is paramount and code is often generated by autonomous agents. Writing hand-derived backpropagation or managing warp divergence in traditional GPU languages introduces silent, catastrophic errors. Crisp’s non-Turing complete architecture turns runtime footguns into strict compile-time errors. With native, mathematically rigorous reverse-mode auto-differentiation, interprocedural uniformity passes, and absolute termination guarantees, Crisp allows both human engineers and AI code assistants to generate perfectly verifiable, deeply optimized GPGPU kernels without hallucinating runtime failures.
